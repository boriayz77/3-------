# Telegram AI Bot with GigaChat

Telegram bot on `aiogram 3` with responses generated by Sber `GigaChat`.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Fill `.env` with your Telegram token, GigaChat credentials, and Supabase settings.

## Supabase setup

1. Create a Supabase project.
2. Open `SQL Editor` in the Supabase dashboard.
3. Run the SQL from `supabase_schema.sql`.
4. Open `Project Settings` -> `API`.
5. Copy `Project URL` to `SUPABASE_URL`.
6. Copy `service_role` key to `SUPABASE_SERVICE_ROLE_KEY`.

Use the service role key only on the server where this bot runs. Do not expose it in client-side code or public repositories.

## Run

```powershell
python bot.py
```

## Commands

- `/start` resets the current dialog and shows help.
- `/help` shows available commands.
- `/chats` shows AI chat selector.
- `/newchat` creates and selects a new AI chat.
- `/reset` clears the current dialog context.
- `/botmsg @bot_username text` sends a private message to another bot via Telegram Bot API 10.0 bot-to-bot communication.

## Bot-to-bot private messages

Telegram Bot API 10.0 allows a bot to send a private message to another bot by passing the recipient bot's `@username` to `sendMessage`.

Example:

```text
/botmsg @OtherBot hello from this bot
```

For this to work, Bot-to-Bot Communication Mode must be enabled for both bots: the sender bot and the recipient bot. If it is disabled for either bot, Telegram will reject the request.

## Environment Variables

- `TELEGRAM_BOT_TOKEN` - Telegram bot token from BotFather.
- `GIGACHAT_CREDENTIALS` - GigaChat authorization key.
- `GIGACHAT_SCOPE` - API scope, usually `GIGACHAT_API_PERS`.
- `GIGACHAT_MODEL` - model name, default `GigaChat`.
- `GIGACHAT_VERIFY_SSL_CERTS` - `true` or `false`, default `false`.
- `SUPABASE_URL` - Supabase project URL.
- `SUPABASE_SERVICE_ROLE_KEY` - Supabase service role key for server-side database access.
- `MAX_HISTORY_MESSAGES` - number of stored messages per AI chat.
