# Ремонтный консультант

Учебный Telegram-бот на Python, aiogram 3.0, GigaChat и Supabase.

Бот помогает пользователю получить консультацию по ремонту: собирает комнату, тип ремонта и вопрос, затем формирует план работ и список материалов через GigaChat. Supabase хранит пользователей, консультации и историю сообщений.

## Запуск

1. Создайте виртуальное окружение.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и заполните переменные.
   В `GIGACHAT_CREDENTIALS` нужен authorization key из личного кабинета GigaChat API.
   Не вставляйте туда OAuth access token.
4. Создайте таблицы в Supabase из файла `schema.sql`.
5. Запустите бота:

```bash
python main.py
```

## Команды

- `/start` — запуск бота
- `/help` — помощь
- `/new` — новая консультация
- `/materials` — подбор материалов
- `/plan` — план работ
- `/history` — история консультаций
- `/reset` — сброс текущего сценария
