# Agent.md

## Название проекта

Ремонтный консультант

## Идея

Telegram-бот помогает людям, которые делают ремонт дома, получить простую консультацию по порядку работ и выбору материалов. Пользователь описывает комнату, тип ремонта и свой вопрос, а бот отвечает понятным языком. GigaChat помогает составлять планы, объяснять этапы ремонта и предлагать подходящие материалы.

## Целевая аудитория

Люди, которые делают ремонт дома самостоятельно или хотят лучше понимать, что нужно обсудить с мастерами. Бот подойдет новичкам, которым сложно разобраться в порядке работ и выборе материалов.

## Проблема пользователя

Пользователь не всегда понимает, с чего начать ремонт, какие материалы выбрать и в каком порядке выполнять работы. Из-за этого можно купить лишнее, пропустить важный этап или сделать работу в неправильной последовательности.

## Основной сценарий

1. Пользователь запускает бота командой /start.
2. Бот кратко объясняет, что может помочь с планом ремонта и подбором материалов.
3. Пользователь выбирает новую консультацию командой /new.
4. Бот спрашивает комнату, например кухня, ванная, спальня или коридор.
5. Бот спрашивает тип ремонта, например косметический или небольшой капитальный.
6. Пользователь пишет вопрос или задачу.
7. GigaChat формирует понятный ответ: порядок работ, советы и список материалов.
8. Бот сохраняет консультацию в Supabase.
9. Пользователь может открыть историю командой /history или начать заново командой /reset.

## Команды бота

- /start — запускает бота и показывает краткое приветствие.
- /help — показывает список команд и объясняет, как пользоваться ботом.
- /new — начинает новую консультацию по ремонту.
- /materials — помогает подобрать материалы под комнату и тип ремонта.
- /plan — составляет примерный порядок ремонтных работ.
- /history — показывает прошлые консультации пользователя.
- /reset — сбрасывает текущую консультацию и начинает заново.

## Использование GigaChat

GigaChat отвечает за интеллектуальную часть проекта:

- отвечает на вопросы пользователя о ремонте;
- объясняет порядок работ простыми словами;
- помогает составить план ремонта для выбранной комнаты;
- предлагает материалы под задачу пользователя;
- делает краткое резюме консультации;
- помогает пользователю понять, что лучше сделать первым.

## Использование Supabase

Supabase используется для хранения данных пользователей, консультаций и истории общения.

### users

В таблице хранятся данные о пользователе:

- id пользователя в Telegram;
- имя пользователя;
- дата первого запуска бота;
- текущая выбранная комната;
- текущий тип ремонта.

### sessions или requests

В таблице хранятся обращения пользователя:

- id консультации;
- id пользователя;
- выбранная комната;
- тип ремонта;
- тема обращения;
- список предложенных материалов;
- краткое резюме ответа;
- дата создания консультации.

### messages или history

В таблице хранится история взаимодействия:

- id сообщения;
- id пользователя;
- id консультации;
- текст вопроса пользователя;
- ответ бота;
- дата и время сообщения.

## Минимальная версия MVP

В первой версии бот должен уметь запускаться, принимать новую консультацию и задавать пользователю несколько вопросов: какая комната, какой тип ремонта и что нужно сделать. После этого бот с помощью GigaChat составляет простой порядок работ и предлагает базовый список материалов. Результат сохраняется в Supabase, а пользователь может посмотреть историю консультаций.

## Возможные улучшения

- Добавить выбор бюджета ремонта.
- Добавить сохранение нескольких комнат в одном проекте.
- Добавить напоминания о следующих этапах работ.
- Добавить шаблоны для кухни, ванной, спальни и коридора.
- Добавить оценку примерного количества материалов.
- Добавить кнопки вместо ручного ввода для частых вариантов.
- Добавить избранные советы и списки покупок.

## Технический стек

- Python
- aiogram 3.0
- GigaChat
- Supabase
- python-dotenv

## Итоговое описание для разработки

Нужно разработать Telegram-бота на Python с использованием aiogram 3.0. Бот помогает пользователю получить консультацию по ремонту: собирает комнату, тип ремонта и вопрос, затем отправляет данные в GigaChat для генерации плана работ и подбора материалов. Supabase хранит пользователей, консультации и историю сообщений. В MVP нужно реализовать команды /start, /help, /new, /materials, /plan, /history и /reset, а также сохранение и просмотр истории консультаций.
